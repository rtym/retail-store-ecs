# Business goals

Index for `architecture/drivers/business-goals/`. One linked row per file. The authoritative traceability matrix is in the [drivers README](../README.md).

| ID | Goal (short) | Category | Priority | Status |
|----|--------------|----------|:--------:|:------:|
| [BG-1](BG-1.md) | The account owner and the sample-app maintainers (ST-1, ST-6) need a working, representative polyglot microservice store running on Amazon ECS with AWS managed backing services so that container and managed-service patterns on AWS can be demonstrated, learned and evaluated. | managing change | high | open |
| [BG-2](BG-2.md) | Shoppers (ST-5) need to browse, search, fill a cart and check out so that every completed checkout produces a stored order — the storefront's functional purpose. | product quality | high | at risk |
| [BG-3](BG-3.md) | The account owner (ST-1) needs the environment's running cost to stay proportionate to a demonstration / non-production workload so that the shared account's budget is not consumed by it. | financial | medium | open |
| [BG-4](BG-4.md) | The account owner and the security function (ST-1, ST-4) need the environment to protect shopper data, detect misuse and recover from failure so that it can stay exposed on the public internet inside a shared account — and, if ST-1 decides so, be promoted beyond demonstration use — without unacceptable risk. | responsibility to society & law | high | at risk |
